**By symptom**:

- a prompt was typed but never confirmed, or typed twice → `host-core` (`deliver.ts`, `settle.ts`)
- deferred work fired late, twice, or not at all → `host-work`
- the daemon spent money unwatched → `host-spenders`
- a token, context, cost or limit number wrong or missing → `host-ledgers`
- the CLI's screen was misread (a box, a banner, a question) → `heuristics`
- uploads, artifacts, builds, screenshots, dictation, machine readings → `host-machine`
- the wire, an ackId, a new message type → `protocol`
- a plugin answered a box, or is listed broken → `host-core` (`answergate.ts`)

**Splitting `sessions.ts`, `intents/manager.ts`, `main.ts` or `deliver.ts`:** load `refactoring`;
the cut is in [host-architecture.md](../../../docs/notes/host-architecture.md).

**The security boundary is CLAUDE.md, never a skill** (`origin.ts`, `auth.ts`, `paths.ts`, `scaffold.ts`, the containment guards). Its companions (`deviceledger.ts`, `lanid.ts`, `authroutes.ts`, `ratelimit.ts`, `pair.ts`) are in
[protocol-and-security.md](../../../docs/notes/protocol-and-security.md). Two gates sit beside it and bite an
`api.ts` route editor: `passive.ts` is the default-deny allowlist (`passiveAllows`) for a passive device
token — a route added anywhere is REFUSED to it until added there on purpose; `confirmgate.ts` is the
server half of "the second tap IS the consent" (`CONFIRM_GATED_FIXES`, `/api/onboard`,
`PUT /api/askrules`) — any new consent-type route goes through it.

**The frame every host task touches:**

- `routes/` — the client-message table, keyed by `t` (`session`, `work/`, `system`).
  `durable: true` wraps the handler in `durableOp`; `contain: "cwd"` resolves the client's directory
  through `containRepoDir` first.  **An unknown `t` is ignored, never thrown**.
- `env.ts` — `ROOT` and the three `.env` loads, **`main.ts`'s FIRST import** so every `WATERPLANE_*`
  knob a module reads at import sees the files; the merge is `envfiles.ts`: the shell beats every
  file, a later file beats an earlier one. A new knob may be read at import — never import a host module
  ahead of `env.ts` in `main.ts`, and keep `env.ts`'s own imports env-free. `rootchoice.ts`: root precedence env > `root.json` > auto, read ONCE at boot (a change takes a restart), so it must stay env-free; `root.json` lives in the config dir (never `.env`/state dir); only `AuthManager.canManage` (loopback + Tailscale) writes it; `branddirs.ts` alone spells a legacy dir name and moves state at boot.
- `main.ts` — the entry point: constructions in boot order (singleton registration, `DOCTOR` gate), the `ctx` assignments, `handleClientMessage`, `main()`; exports nothing, its functions live in `server/`.
- `server/` (`ctx.ts`, `clients.ts`, `intentDeps.ts`, `intentEvents.ts`, `billingwire.ts`, `scan.ts`, `deliveries.ts`, `wsops.ts`, `liveness.ts`, `sessionEvents.ts`, `http.ts`, `shutdown.ts`, `firstapp.ts`, `ctxseal.ts`) — `main.ts`'s pieces, factories over `ServerCtx`
  (`ctx.ts`, types only; per-factory inventory: [host-architecture.md](../../../docs/notes/host-architecture.md#server--the-host-routers-frame)). A factory reads `ctx.<x>` at CALL time, never destructures it at
  construction, and registers nothing at import; `main.ts` assigns every member right after its
  definition. **`containRepoDir()` (`wsops.ts`) is the ONE gate on a
  client-named directory** — inside `ROOT` or a discovered worktree, else refuse, never guess.
  `durableOp()` = at-most-once per ackId; **thrown ⇒ not remembered, `ok:false` ⇒ remembered**.
  `shutdown.ts`'s flush ORDER is behaviour, pinned by `hostpins`. `firstapp.ts` runs AFTER
  `intents.start()` (a job resumes into a running store), never under `DOCTOR`.
  `deliveries.ts`' `startPrompt` re-queues only a provably-`retry` failure.
- `acks.ts` — the ackId ledger. Persisted, TTL 45 min, flushed on SIGTERM.
- `jsonstore.ts` — stores persist with `writeJsonAtomic` (tmp + fsync + rename, mode before bytes) and reads with `readJsonGuarded` (a corrupt file is moved to `<name>.corrupt-<ts>`, never overwritten); never `writeFileSync` a store.
- `cli/` — selfupdate runs by explicit command only, `statesnap.ts` is taken by `update` before it switches versions and restored by `--rollback` (a newer host may have converted the stores), `releasesig.ts` is pinned to `deploy/release-pubkey.pem` ⇒ [distribution.md](../../../docs/notes/distribution.md).
- `api.ts` — the HTTP frame: CORS reflection, preflight, dispatch over `routes/apiroutes.ts`'s one
  table. A route is `route(method, pattern, handler)` in a domain table (`routes/apisystem.ts`,
  `apihost.ts`, `apisession.ts`, `apistats.ts`, `apirepofiles.ts` + `apirepowork.ts` under the
  `/api/repos/:id/*` scope; helpers in `apiio.ts`, the matcher in `apitable.ts`). A handler returns
  `false` for "not mine"; first match wins; HTTP tables also take MOUNT entries (`peers/routes`, `peers/agentpeer`, `agentintents`, `agentfollowup`, `onboardroutes`) and `/api/plugin/:id/*`; a new route is a line in
  `packages/host/test/apiroutes.test.mjs`. Only `api.ts` of the flat modules may import `routes/`.
  Artifacts over `STREAM_MIN` are **piped, not buffered**; resumability rests
  on `accept-ranges`, a correct `content-range`, **416 not 200** past the end, and `if-range` — on the
  buffered path too. `artifact?…&stat=1` answers mtime+size and no bytes, behind the same gate.
